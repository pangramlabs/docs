---
title: "Monthly Usage"
description: "Read one API key's recorded billable request count and cost for a UTC month"
api: GET https://text.external-api.pangram.com/usage
---

Return recorded external billable usage for the **calling API key**, across products, for one UTC calendar month. Other keys on the same billing account have separate histories. Replacing a key does not transfer the old key's usage history.

This read works with strict-ZDR keys and zero or negative balances. It does not spend credits or consume inference QPS. Responses use `Cache-Control: no-store`.

## Query parameter

<ParamField query="month" type="string">
  One UTC calendar month in `YYYY-MM` form, such as `2026-10`. Defaults to the current UTC month and includes transactions committed so far. Future months are rejected.
</ParamField>

`month` is the only supported query parameter. Account/key selectors, date ranges, daily breakdowns, and product filters are not supported. Use the dashboard for account-wide history.

## Examples

<CodeGroup>

```bash cURL
curl 'https://text.external-api.pangram.com/usage?month=2026-10' \
  --header "x-api-key: $PANGRAM_API_KEY"
```

```python Python SDK (1.2.0)
from pangram import Pangram

client = Pangram()  # Reads PANGRAM_API_KEY.
usage = client.get_usage(month="2026-10")  # Omit month for the current UTC month.
```

```python Python (requests)
import os
import requests

response = requests.get(
    "https://text.external-api.pangram.com/usage",
    headers={"x-api-key": os.environ["PANGRAM_API_KEY"]},
    params={"month": "2026-10"},  # Omit params for the current UTC month.
    timeout=(10, 30),
)
response.raise_for_status()
usage = response.json()
```

</CodeGroup>

<Note>
`get_usage(month=None, *, timeout=10)` is introduced in SDK 1.2.0, which is not yet released. It returns an `AccountUsage` dictionary. The `requests` example works with older SDK versions. See [SDK error handling](/sdk/python#account-read-errors).
</Note>

## Response

```json
{
  "month": "2026-10",
  "total_requests": 10,
  "total_cost_usd": "0.750000"
}
```

<ResponseField name="month" type="string">
  The selected UTC calendar month in `YYYY-MM` form.
</ResponseField>

<ResponseField name="total_requests" type="integer">
  Count of recorded external billable rows, not all HTTP attempts or bulk parent submissions.
</ResponseField>

<ResponseField name="total_cost_usd" type="string">
  USD decimal string summing recorded charges. Missing or zero historical charges are not recalculated at today's prices.
</ResponseField>

An unused month returns zero requests and `"0.000000"` cost. These values represent credit consumption, not purchases, invoices, or remaining credits. Use [`/balance`](/api-reference/balance) for the available credit balance and decimal arithmetic for USD amounts.

## Read limits and errors

This route shares the independent [account-read budget](/api-reference/balance#read-limits-and-errors) with balance and limits calls. Respect `Retry-After` on `429`.

| Status | Meaning |
| --- | --- |
| `401` | Missing, malformed, revoked, inactive, or otherwise invalid key/account. |
| `422` | Invalid/future month or unsupported query parameter. |
| `429` | Account-read rate or concurrency limit; observe `Retry-After`. |
| `503` | Account lookup unavailable or timed out; retry the read later. |
